ชุดโครงการชุมชนที่สร้างขึ้นบน NEXUS

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ NEXUS ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-nexus](https://github.com/awesome-nexus/awesome-nexus) และ [nexus.cafe](https://nexus.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
